    Interface StructureOptions<T>

    Structure — a generic algebraic structure (group, ring, field, …) defined by its membership criteria, operations, inverses and identities. Given those, it provides linear algebra (vectors and matrices) over the structure, mirroring RealMath/ComplexMath but parameterised by arbitrary operations.

    Ported from Mallory's ActionScript Structure. The AS3 matrix section was essentially non-functional — several methods were mistakenly declared static yet called instance operations, many referenced undefined capitalised names (Scale, ScaleMatrix, Determinant), crossProduct overwrote its first operand with the second and read index 3, powerMatrix invoked a method that does not exist, and vectorSum/vectorProduct never returned. All of this is reconstructed here as working instance methods. The chriteria spelling is corrected to criteria.

    interface StructureOptions<T> {
        criteria?: ((element: unknown) => boolean)[];
        equality?: (a: T, b: T) => boolean;
        identities?: T[];
        inverses?: ((x: T) => T)[];
        operations?: ((a: T, b: T) => T)[];
        wrap?: (x: unknown) => T;
    }
