    Class Cycle<T>

    Cycle — a permutation cycle over an ordered list of distinct elements. Ported from Mallory's ActionScript Cycle.

    Bug fix / modernisation: the AS3 constructor silently left _elements undefined when the input contained repeats (every later method then threw); this version rejects repeats up front with a clear error. The misspelled transpotions methods are corrected to transpositions.
