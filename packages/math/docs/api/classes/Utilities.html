    Class Utilities

    Utilities — small general-purpose helpers.

    In the ActionScript original the entire body of this class was commented out. The helpers were clearly intended to ship (they are referenced conceptually throughout the library and RoundTo is re-implemented ad hoc elsewhere), so they are revived here as ordinary functions. Array helpers that merely duplicate built-ins (CloneArray, MapArray, isMember) are kept for API parity.
