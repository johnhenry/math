    Class VectorCalculus

    VectorCalculus — multivariable differential calculus: gradients, Jacobians, divergence, curl, and Hessians. Built entirely on existing exact-derivative machinery rather than a new autodiff engine: gradient/jacobian reuse DualNumber forward-mode autodiff (exact, first-order); symbolicGradient reuses Symbolic differentiation/evaluation for string-expression functions.

    hessian is the one approximate method — it takes central differences of the exact gradient (not of f itself), which is more accurate than a naive finite-difference Hessian without the scope of implementing second-order (hyperdual) numbers.
