    Class IntUtils

    IntUtils — convert integers (and numeric strings) into English words.

    Ported from Mallory's ActionScript IntUtils. The peculiar comma-joined grouping of the original output is preserved so behaviour is unchanged, but two spelling bugs are fixed: "fourty" → "forty" and "ninty" → "ninety".

    Passing a string lets you exceed JS's safe-integer range, exactly as the AS3 version did to sidestep ActionScript's number limits.
